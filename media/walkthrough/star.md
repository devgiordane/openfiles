# You're set

Next time an agent edits files, look for:

- the **AI** badge on changed files in the Explorer
- the **AI Edits** view in the OpenFiles sidebar, with a checkbox per file
- the status bar item with unreviewed files and errors

**Review Next Changed File** marks the current file as reviewed and opens the next one, errors first.

OpenFiles is free and open source. Issues, ideas and agent integrations are welcome at [github.com/devgiordane/openfiles](https://github.com/devgiordane/openfiles).
