# Getting help

- **Something isn't detected or opened:** run **OpenFiles: Run Doctor** and include its report in a [bug report](https://github.com/devgiordane/openfiles/issues/new?template=bug_report.yml). The **OpenFiles** output channel (View → Output) has the log.
- **Your agent isn't supported:** open an [agent support request](https://github.com/devgiordane/openfiles/issues/new?template=agent_support.yml).
- **Questions and ideas:** [Discussions](https://github.com/devgiordane/openfiles/discussions).
- **Docs:** https://devgiordane.github.io/openfiles
